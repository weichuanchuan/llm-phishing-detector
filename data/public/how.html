把邮件作为附件发送

或下载为 .eml 文件后再上传

下方提供常见邮件客户端的简要步骤

Gmail（手机端）

移动端暂不支持直接“作为附件转发”。请保持原文不改，直接转发：

  • 打开需要分析的邮件，点击转发。
  • 不要修改主题与正文。
  • 收件人填写 start@mailcheck.help 并发送。
Outlook（手机端）

移动版 Outlook 同样没有附件转发：

  • 打开目标邮件并点击转发。
  • 保持主题和正文不变。
  • 发送至 start@mailcheck.help。
Apple Mail（iOS）

iPhone/iPad 不支持直接附加邮件：

  • 打开邮件，点击转发。
  • 不要编辑主题或正文。
  • 发送到 start@mailcheck.help。
Samsung Mail

暂无“作为附件转发”功能：

  • 点击转发，保持原文。
  • 收件人填写 start@mailcheck.help 并发送。
Gmail（桌面端）

可先下载为 .eml 文件，再作为附件发送：

  • 打开邮件，点击右上角的“三个点”，选择下载邮件。
  • 新建邮件，附加下载的 .eml 文件。
  • 收件人写 start@mailcheck.help 后发送。
Outlook（桌面端）

支持直接“作为附件转发”：

  • 选中邮件，点击更多操作 → 作为附件转发。
  • 收件人填写 start@mailcheck.help 并发送。
Thunderbird

可直接附加原邮件：

  • 选择邮件，点击菜单消息 → 作为附件转发。
  • 收件人写 start@mailcheck.help，即可发送。
Apple Mail（macOS）

支持直接作为附件转发：

  • 选择邮件，点击邮件 → 作为附件转发。
  • 发送到 start@mailcheck.help。
Yahoo Mail / AOL / Spark / BlueMail / Newton / Zoho / Fastmail / Windows 邮件

这些客户端通常不提供附件转发。请直接转发原邮件，不要修改主题和正文，收件人填写 start@mailcheck.help。

GMX Mail

可下载为 .eml 后发送：

  • 打开邮件，选择打印/保存并保存为 .eml。
  • 新建邮件，附加该文件并发送到 start@mailcheck.help。
WEB.DE Mail

暂不支持附件转发，请直接转发原邮件至 start@mailcheck.help，勿更改内容。

ProtonMail / Tutanota（加密邮箱）

默认不提供 .eml 导出，直接转发即可。若需导出，请先解密并保存为 .eml，但可能降低安全性。

所有邮件仅用于安全分析，处理完毕后即删除。请放心使用。
